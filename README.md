# Taidi Speaker Site

Static bilingual speaker website built with Astro 5 and Tailwind CSS.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

Before launch, replace the placeholder email, LinkedIn URL and canonical domain. Add approved PDFs under `public/files/`, then replace the disabled material buttons with links. Outstanding content decisions are tracked in `DESIGN.md`.
